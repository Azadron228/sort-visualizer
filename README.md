# Сравнение сортировок

Программа на Python и matplotlib сравнивает пузырьковую (обменную),
шейкерную сортировки и сортировку включением (вставками).
Два графика в одном окне показывают среднее число сравнений элементов и среднее время
сортировки в миллисекундах: **меньше — лучше**.

![График сложности сортировок](docs/screenshot.png)

## Запуск

Установка зависимостей один раз:

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

```bash
python comparison.py
python animation.py
```

После активации `venv` команда `python` использует зависимости проекта.
Интерактивное окно Matplotlib работает через PyQt6 из `requirements.txt`.

`comparison.py` строит графики числа сравнений и времени, а `animation.py` показывает процесс
сортировки столбиков.

## Настройки

В начале `comparison.py`:

- `ALGORITHMS` — какие алгоритмы сравнивать;
- `SIZES` — размеры массивов (по умолчанию от 100 до 1000 с шагом 100);
- `SAMPLES` — сколько массивов каждого размера брать для усреднения;
- `SEED` — одинаковое значение даёт одинаковые случайные массивы;
- `ARRAY_TYPE` — тип массивов; варианты перечислены в коде.

В начале `animation.py` можно выбрать `ALGORITHM`, `SIZE`, `SEED` и `INTERVAL`.
Значения `ALGORITHM`: `"Пузырьковая (обменная)"`, `"Шейкерная"`, `"Включением"`.

Каждый алгоритм находится в своём файле в `algorithms/`. Чтобы добавить новый,
создайте файл, добавьте импорты и строку в `ALGORITHMS`. Функция должна возвращать
`(отсортированный_массив, число_сравнений)`, сохраняя исходный массив.

O-нотация в легенде указывает среднюю сложность алгоритмов — O(n²).

### Как работают сортировки

- Пузырьковая (обменная) сортировка сравнивает соседние элементы справа налево.
  После каждого прохода минимум оказывается в начале оставшейся части массива.
- Шейкерная сортировка сравнивает соседние элементы проходами слева направо
  и справа налево, сужая границы (первый проход — справа налево). Если обменов нет, сортировка завершается.

- Сортировка включением (вставками) берёт очередной элемент и перемещает его
  влево соседними обменами, пока он не займёт своё место в отсортированной части.
  На уже отсортированном массиве выполняет n−1 сравнений.

## Как объяснить программу

`comparison.py` работает в четыре шага:

1. `generate_array` создаёт исходные массивы.
2. `measure_algorithms` запускает все сортировки на одинаковых данных и измеряет
   время каждого вызова через `perf_counter`, переводя секунды в миллисекунды.
3. Алгоритмы возвращают отсортированный массив и число сравнений.
4. `show_results` строит два графика средних значений по `SAMPLES` запускам.

Время включает копирование массива и подсчёт сравнений внутри алгоритма.
Генерация исходных данных, анимация и построение графиков в замер не входят.
Результаты времени могут немного отличаться между запусками из-за нагрузки системы.

Обе программы импортируют одни и те же функции из папки `algorithms`.
`comparison.py` просто получает результат и число сравнений. `animation.py`
передаёт алгоритму функцию `on_step`, которая сохраняет состояние массива после
каждого шага. Поэтому код сортировок не дублируется.

`FuncAnimation` по очереди передаёт сохранённые состояния в `draw`, а `draw`
меняет высоту и цвет столбиков. Синие элементы ожидают обработки, красные сейчас
сравниваются, зелёные означают завершённую сортировку.
