# Сравнение сортировок

Запуск:

```bash
python main.py
```

Откроется один простой график: размер массива по горизонтали, среднее число
сравнений по вертикали. Каждая линия соответствует одному выбранному алгоритму.
По умолчанию используются 48 случайных массивов: 6 размеров × 8 образцов.
Все алгоритмы получают одинаковые данные.

## Выбор алгоритмов в коде

Каждая сортировка находится в отдельном файле:

- `algorithms/bubble_sort.py` — пузырьковая;
- `algorithms/quick_sort.py` — быстрая.

В начале `main.py` импортируйте нужные функции и укажите их в `ALGORITHMS`:

```python
from algorithms import bubble_sort, quick_sort

ALGORITHMS = {
    "Пузырьковая — O(n²) в среднем": bubble_sort,
    "Быстрая — O(n log n) в среднем": quick_sort,
}
```

Чтобы показать только один алгоритм, оставьте одну строку. Для нового алгоритма
создайте отдельный файл в `algorithms/`, добавьте импорт в `algorithms/__init__.py`,
затем импорт и строку в словарь в `main.py`. Функция должна
работать с копией входного массива и возвращать `(отсортированный_массив, число_сравнений)`.

Размеры задаются в `SIZES`, число образцов — в `SAMPLES`, тип массива — в
`ARRAY_TYPE`. Варианты типов перечислены рядом с настройками в `main.py`.

## Установка зависимостей один раз

Требуется matplotlib и графический backend, например TkAgg с установленным Tk.

```bash
python -m venv .venv
.venv/bin/python -m ensurepip
.venv/bin/python -m pip install -r requirements.txt
python main.py
```

При наличии `.venv` программа автоматически использует его Python.
Скриптов запуска, CLI и экспорта нет.

Проверка алгоритмов:

```bash
python -m unittest discover -s tests -v
```
